# Phase 4: Navigation, technical SEO, GA4 and Search Console

## Navigation
Desktop/mobile top: Features, How It Works, Documentation, Blog, About; Login/Get Started. Footer groupings: Platform (Features, How It Works, Supported Apps, Pricing), Resources (Docs, Help/FAQ, Blog), Company (About, Contact, Security), Legal (Terms, Privacy, AUP, Cookies, Service and relevant deletion/disclosure links). Keep routes consistent and accessible.

## SEO
Unique title/meta/description, clean stable URL and 301s for changed slugs, canonical, sitemap, robots, internal links, structured data only where truthful, author and review dates, mobile/Core Web Vitals, accessible content. Prevent indexing of private dashboard/log routes and leakage via metadata.

## Analytics
Set up/Search Console ownership after authorized account access. Add GA4 only to approved public surfaces; pageview, Get Started, docs visits, blog engagement and non-sensitive conversion event. Never send email, repository identifiers, env vars, secrets or deployment logs. Check no duplicate events, use test/internal filters. Review retention, consent under applicable jurisdictions, Google Consent Mode settings, Privacy/Cookie disclosure and user preference controls. Avoid sensitive admin/deployment dashboards.

## AdSense
Existing educational blog/content strategy must be original and useful. No promises of approval. No misleading ad/navigation combinations. Confirm consent and publisher requirements prior to advertising script activation. Do not create fabricated author credentials, testimonials or ratings.
