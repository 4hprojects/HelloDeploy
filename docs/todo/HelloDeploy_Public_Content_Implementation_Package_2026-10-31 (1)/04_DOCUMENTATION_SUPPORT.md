# Phase 3: Documentation and Support

## Documentation IA
Getting Started; quickstart deploy of a minimal supported Node.js app; GitHub permissions; environment vars and secrets; ports/build/start; troubleshooting failed install/build/crashes; logs; domain and TLS behavior only if supported; backup responsibility; app stop/delete and repo disconnect.

## Support
Searchable FAQ or simple indexed help collection; contextual help for common failure states; best-effort contact route; separate private vulnerability disclosure channel. Forms must explicitly warn not to send credentials, private tokens, production logs containing secrets. Verify anti-spam and privacy handling.

## Acceptance
Instructions tested against current production-like workflow, version-specific code examples, working links, no unverifiable turnaround guarantee. Docs updated with changed behavior in each future PR.
