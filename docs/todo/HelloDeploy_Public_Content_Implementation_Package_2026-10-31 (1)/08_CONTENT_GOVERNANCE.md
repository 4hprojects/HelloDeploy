# Phase 6: Content maintenance and governance

Create maintainable content register for each policy, public page and doc: owner, reviewer, last review, effective date, next review, source links and status. Review on major feature, authorization, pricing, privacy/data flow, infrastructure, regulation or provider changes. Propose monthly link/content smoke-check and quarterly substantive review, adjusted to team capacity.

Integrate docs and policy-impact checkbox into pull requests; add versioned change log and user notices for material terms/privacy changes. Require legal/owner approval on material policy and payment/pricing text. Preserve history and stable URLs. Automate light link/SEO/accessibility checks where feasible without invasive production tasks.
