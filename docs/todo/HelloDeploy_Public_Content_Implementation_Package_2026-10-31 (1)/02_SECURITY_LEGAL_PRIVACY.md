# Phase 1: Legal, security, and privacy content

## Draft distinct, cross-linked pages
- Terms: eligibility, account responsibilities, ownership of source code, limited authorization to build/deploy/run/restart/maintain applications, GitHub access, AUP, change notices, jurisdiction, suspension and termination.
- Disclaimer of Warranties, Limitation of Liability, Indemnification: deployment interruptions, data loss, third-party providers, security responsibilities, caps suitable for free tier, non-waivable user rights. Qualified legal review required before publication as finalized legal terms.
- Privacy: verified controller/operator and contact, data categories, processing purposes/lawful bases, OAuth scopes, secrets, deployment metadata/logs, cookies, recipients/processors, transfers, retention/deletion, rights requests, incident process, age policy.
- AUP: malware, phishing, spam, illicit content, mining and abusive resources prohibited; explicit adult services restricted with lawful educational/health distinctions. Clear notice/remediation, urgent suspension, appeal, record keeping.
- Infrastructure/Service: best-effort service, measured CPU/RAM/disk/network/build limits, maintenance, failures, support, backups and responsibilities, data export when feasible.
- Cookie/Tracking Policy, deletion and account closure explanation, public Security page and responsible disclosure route.

## Technical controls to verify or implement where feasible
GitHub least privilege/revocation; protect tokens, env vars and logs; RBAC and admin access review; production-safe application isolation; session and CSRF protections; throttling; incident evidence and response workflow. No claim of automated scanning, encryption, MFA, instant deletion or 24/7 response unless tested.

## International use
Philippine laws form baseline. Determine jurisdictional triggers for EU/UK, US states and actual service regions. Governing law does not override non-waivable rights. Verify cross-border processor terms and cookie consent requirements. Document legal counsel review as a release gate for legally material drafts.

## Exit criteria
Every public legal claim tied to verified implementation or flagged explicitly as draft/unpublished; navigation paths and policy versioning; no secret disclosure; tests for relevant security controls. Keep existing legal pages accessible while replacement text undergoes review.
