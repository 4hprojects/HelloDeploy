## Section: How HelloDeploy Works

### H2

```text
How HelloDeploy Works
```

### Step 1: Add Your Project

Start with the application you want to deploy.

HelloDeploy collects the information needed to prepare the project for deployment.

Where supported, the platform may help identify common project configuration requirements.

### Step 2: Configure the Deployment

Set the values your application needs.

Depending on the project, this may include:

- build command
- start command
- application port
- environment variables
- runtime settings

### Step 3: Deploy

HelloDeploy runs the required deployment steps and starts the application using the configured settings.

### Step 4: Review the Result

See whether the deployment completed successfully.

If something fails, deployment logs help identify what needs to be fixed.

### Step 5: Connect Your Domain

Use a HelloDeploy project subdomain or connect a supported custom domain.

### Step 6: Publish Updates

Redeploy your project when you release a new version.

Configure and publish supported applications through a structured deployment process.

Review deployment activity and identify build or startup errors.

Keep application configuration separate from your source code.

Connect your own supported domain to a deployed project.

### HTTPS

Serve supported deployments securely over HTTPS.

### Redeployment

Publish updated versions without recreating the deployment from the beginning.

Trigger supported deployments from external workflows using a private deployment endpoint.
