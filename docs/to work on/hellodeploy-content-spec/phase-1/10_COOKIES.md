# Phase 1: Cookie Policy Specification

URL:

```text
/cookies
```

## H1

```text
Cookie Policy
```

## Required Sections

### Essential Cookies

Used for core site functionality.

Examples may include:

- authentication
- security
- session state

### Preference Cookies

Used to remember user choices where applicable.

### Analytics Cookies

Used to understand site usage if analytics tools are enabled.

### Advertising Cookies

Only describe advertising cookies if advertising services are implemented.

### Third-Party Cookies

Explain when external services may set cookies.

### Cookie Controls

Explain how users can manage cookie preferences where supported.

### Policy Updates

Explain that the policy may change when tools or services change.

## Implementation Rule

The cookie policy must match the actual tracking and advertising tools used on the site.
