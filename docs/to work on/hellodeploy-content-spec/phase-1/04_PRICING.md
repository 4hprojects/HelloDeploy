## Pricing Status

Every plan below is **proposed**. Display a persistent banner at the top of the page:

```text
Proposed Pricing
```

Do not present draft pricing as permanent.

## No Checkout Exists Yet

HelloDeploy has no billing system, no payment provider, and no plan tiers in the platform. Resource limits are set per user or per project by an administrator.

Therefore:

- no plan card may carry a CTA that implies a purchase
- every paid-plan CTA points to `/contact`, not a checkout
- do not imply that upgrading is self-service

Revisit this whole page when billing is implemented.

## FAQ

### Can I start for free?

Yes. The Free plan is intended for learning and testing small projects.

### Can I connect my own domain?

Supported paid plans can connect custom domains.

### Is domain registration included?

No, unless explicitly included in a future plan.

### Can I upgrade later?

Yes. Projects should have a clear upgrade path.

### Are databases included?

Database support depends on the current HelloDeploy platform. Applications may also connect to supported external database providers.

### What happens if my application needs more resources?

HelloDeploy should provide a clear upgrade path when a project exceeds the limits of its current plan.

### Do I need to manage Linux or Nginx myself?

HelloDeploy is designed to handle common deployment infrastructure tasks so users do not need to manually configure every server component.
