# Phase 1: Privacy Policy Specification

URL:

```text
/privacy
```

## Purpose

The Privacy Policy must reflect the actual HelloDeploy implementation.

Do not copy another company's policy.

Do not claim that data is never collected unless technically verified.

## Required Sections

### Information Users Provide

Possible categories:

- account information
- email address
- profile information
- support requests
- billing information if applicable

### Authentication Information

Explain how authentication data is handled and whether third-party authentication services are used.

### Deployment Information

Possible categories:

- project names
- deployment metadata
- runtime settings
- domain configuration
- repository metadata
- deployment history

### Environment Variables and Secrets

Describe how sensitive configuration values are handled.

Do not expose actual values in public examples.

### Logs

Explain what logs may be collected for:

- deployment
- troubleshooting
- security
- service operation

### Analytics

Disclose analytics services if used.

### Cookies

Describe essential, preference, analytics, and advertising cookies where applicable.

### Advertising

If AdSense or another advertising service is enabled, update this section before ads go live.

### Payments

Explain whether payment information is processed directly or through a payment provider.

### Third-Party Services

List categories of third-party services used by the platform.

### Data Retention

Explain how long different data categories may be retained or the criteria used.

### Data Deletion

Explain how users can request or initiate deletion where supported.

### Security

Describe reasonable security measures without promising absolute security.

### User Rights

Include rights appropriate to applicable law and supported user regions.

### Contact

Provide an official privacy contact channel.

## Legal Review Requirement

Before production use, review the final policy against:

- actual product behavior
- deployed analytics
- authentication providers
- payment providers
- advertising services
- applicable jurisdiction
