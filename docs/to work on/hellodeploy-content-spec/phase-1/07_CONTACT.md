# Phase 1: Contact

URL:

```text
/contact
```

## SEO Title

```text
Contact HelloDeploy | Support, Feedback and Inquiries
```

## Meta Description

```text
Contact HelloDeploy for deployment support, account questions, bug reports, feature requests, billing inquiries, partnerships, and general questions.
```

## H1

```text
Contact HelloDeploy
```

## Intro

Use this page if you need help with HelloDeploy or want to contact the project team.

## Contact Categories

### Deployment Support

Use for:

- failed deployment
- project configuration
- domain connection
- environment variables
- deployment logs

### Account Support

Use for:

- sign in
- account access
- profile issues
- account settings

### Bug Report

Use for:

- unexpected errors
- broken pages
- incorrect behavior
- deployment problems that appear platform-related

### Feature Request

Use to suggest:

- new deployment features
- new runtime support
- dashboard improvements
- documentation improvements

### Billing

Use for:

- plan questions
- payment questions
- subscription issues
- upgrade or downgrade questions

### Business or Partnership Inquiry

Use for:

- partnerships
- institutional use
- organization deployments
- business inquiries

## Recommended Form Fields

- name
- email
- category
- subject
- message
- project URL if relevant
- deployment ID if relevant
- optional screenshot attachment if supported

## Security Reminder

Do not ask users to submit:

- passwords
- private keys
- API secrets
- tokens
- secret environment variables
