# Reusable Troubleshooting Article Template

## SEO Title

Use a problem-focused title.

Example:

```text
HelloDeploy Build Failed | Causes and Fixes
```

## Meta Description

Summarize:

- symptom
- likely cause category
- what the guide helps fix

## H1

Use the exact user problem.

Example:

```text
Build Command Failed
```

## Quick Answer

Give the most likely explanation in 2 to 4 sentences.

## Symptoms

List what the user may see.

## Common Causes

List realistic causes.

## How to Check

Provide numbered diagnostic steps.

## How to Fix

Provide fixes by cause.

## How to Verify

Explain what success looks like.

## HelloDeploy-Specific Checks

List relevant UI locations.

Only use verified labels.

## Security Reminder

Where relevant, remind users not to expose secrets in logs or screenshots.

## Related Documentation

Link to relevant docs.

## Related Learn Articles

Link to conceptual explanations.

## Contact Support

Explain what information to include if the issue remains unresolved.

Do not request passwords, tokens, or private keys.
