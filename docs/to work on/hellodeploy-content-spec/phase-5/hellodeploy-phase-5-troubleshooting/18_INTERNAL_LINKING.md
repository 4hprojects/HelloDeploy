# Phase 5 Internal Linking

## Documentation

Troubleshooting pages should link to the exact configuration area involved.

Examples:

### Build

```text
/docs/build-configuration
/docs/deployment-logs
```

### Startup

```text
/docs/start-command
/docs/application-port
/docs/deployment-logs
```

### Environment Variables

```text
/docs/environment-variables
```

### Domains

```text
/docs/custom-domain
/docs/dns-configuration
/docs/https-and-ssl
```

## Learn Content

Link to conceptual articles when the reader may need background.

Examples:

- What Is DNS?
- Why HelloDeploy Uses a CNAME
- What Is an Application Port?
- What Are Environment Variables?
- What Are Deployment Logs?
- Application Works Locally but Fails on HelloDeploy

## Related Troubleshooting

Cross-link closely related problems.

Example:

```text
Custom Domain Is Not Resolving
→ DNS Points to Wrong Server
→ Root Domain Works but WWW Does Not
→ SSL Certificate Is Not Working
```

## Contact

All troubleshooting pages should offer a final support path without making support the first step.
