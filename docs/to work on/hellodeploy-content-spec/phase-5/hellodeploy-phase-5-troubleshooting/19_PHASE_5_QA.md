# Phase 5 QA Checklist

## Required Guides

- [ ] Dependency Installation Failed
- [ ] Build Command Failed
- [ ] Application Starts but Website Does Not Load
- [ ] Application Port Is Incorrect
- [ ] Missing Environment Variable
- [ ] Application Keeps Restarting
- [ ] Custom Domain Is Not Resolving
- [ ] SSL Certificate Is Not Working
- [ ] 502 Bad Gateway
- [ ] 404 After Deployment
- [ ] Root Domain Works but WWW Does Not
- [ ] WWW Works but Root Domain Does Not
- [ ] DNS Record Points to Wrong Server
- [ ] Application Works Locally but Fails on HelloDeploy

## Accuracy

For each guide:

- [ ] Symptom is realistic
- [ ] Causes are technically plausible
- [ ] HelloDeploy-specific behavior is verified
- [ ] UI labels are verified
- [ ] No fake error messages
- [ ] No fake timeout values
- [ ] No unsupported health-check claims
- [ ] No unsupported restart claims

## Troubleshooting Quality

- [ ] Quick answer is clear
- [ ] Diagnostic steps are ordered
- [ ] Fixes map to causes
- [ ] Verification step exists
- [ ] Related docs are linked
- [ ] Related Learn articles are linked

## Security

- [ ] No secrets in screenshots
- [ ] No real deploy hooks
- [ ] No private keys
- [ ] Logs sanitized
- [ ] No real user data

## SEO

- [ ] Unique title
- [ ] Unique meta description
- [ ] One H1
- [ ] Clean URL
- [ ] Canonical URL
- [ ] Breadcrumb
- [ ] Internal links

## UX

- [ ] Easy to scan
- [ ] Short paragraphs
- [ ] Numbered diagnostic steps
- [ ] Clear expected result
- [ ] Mobile readable

## Phase Completion

Phase 5 is complete when:

- [ ] all initial guides are published
- [ ] troubleshooting hub links to them
- [ ] docs link to relevant guides
- [ ] support escalation path exists
- [ ] real platform issues have been incorporated where available
