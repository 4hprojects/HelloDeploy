# Content Quality Rules

## Core Standard

Every public page should answer a real user need.

## Prefer Specific Questions

Good:

- What Is a Deploy Hook and When Should You Use One?
- Why Does My Website Work Locally but Fail After Deployment?
- What Is an Application Port?
- How Does DNS Connect a Domain to a Server?

Weak:

- Amazing Deployment Tips
- Best Hosting Secrets
- Powerful Cloud Features
- Everything You Need to Know About Technology

## Use Real Examples

Prefer:

- HelloDeploy screenshots
- actual deployment flows
- real DNS examples
- sanitized deployment logs
- real configuration examples
- real case studies
- actual troubleshooting experiences

## Avoid Unsupported Claims

Do not claim:

- unlimited hosting
- unlimited bandwidth
- support for every language
- zero downtime
- automatic scaling
- automatic backups
- 100 percent uptime
- enterprise security
- instant deployment

unless verified and contractually supported.

## Avoid Thin Content

Do not publish pages that contain only:

- title
- two paragraphs
- CTA
- advertisement

The page should fully answer the topic.

## Writing Style

Use:

- short paragraphs
- clear headings
- examples
- simple technical explanations
- diagrams where useful
- tables where useful

Explain the simple version before introducing advanced terminology.
