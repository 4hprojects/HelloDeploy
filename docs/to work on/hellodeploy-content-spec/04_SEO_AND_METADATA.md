# SEO and Metadata Requirements

Every public content page must include:

- unique page title
- unique meta description
- one H1
- logical H2 and H3 hierarchy
- canonical URL
- Open Graph title
- Open Graph description
- Open Graph image where relevant
- descriptive image alt text
- breadcrumb support where appropriate
- structured data where appropriate
- author for editorial articles
- published date for editorial articles
- updated date for editorial articles

## URL Rules

Use readable URLs.

Good:

```text
/learn/what-is-web-deployment
/learn/what-is-dns
/docs/environment-variables
```

Avoid:

```text
/page?id=812
/blog/post-19
/article123
```

## Content Duplication Rule

Do not create separate pages for nearly identical keyword variants.

Example:

Do not create all three unless they have distinct intent:

- what is VPS hosting
- what is a VPS
- VPS meaning

Prefer one strong article.

## Internal Linking

Every educational article should link to:

- at least one relevant related article
- a relevant documentation page where applicable
- a relevant HelloDeploy product page where useful

Do not force product CTAs into every paragraph.
