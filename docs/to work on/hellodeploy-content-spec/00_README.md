# HelloDeploy Content Implementation Pack

## Purpose

This folder contains the implementation-ready content specification for the public HelloDeploy website.

The previous single-file plan has been split into smaller Markdown files so a developer or coding agent can work on one page or content area at a time without mixing requirements.

## Immediate Priority

Phase 1 must be completed before large-scale article publishing.

Phase 1 contains the public product and trust foundation:

1. Homepage
2. Features
3. How It Works
4. Pricing
5. Supported Runtimes
6. About
7. Contact
8. Privacy Policy
9. Terms of Service
10. Cookie Policy
11. Acceptable Use Policy
12. Navigation and Footer
13. SEO and metadata
14. Phase 1 QA

## Global Rules

- Do not claim support for a runtime unless verified.
- Do not promise unlimited resources.
- Do not publish exact CPU, RAM, storage, bandwidth, build-minute, SLA, or uptime limits until validated.
- Do not place advertising inside operational product screens.
- Do not publish placeholder text.
- Do not generate thin pages only for SEO.
- Use real HelloDeploy screenshots, deployment examples, and case studies where possible.
- Keep product functionality separate from public informational content.
