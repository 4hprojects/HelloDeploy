# Phase 4 SEO and Structured Data

## Page Title Pattern

Prefer:

```text
How [Project] Was Deployed With HelloDeploy
```

or:

```text
Deploying [Project] With HelloDeploy
```

## Meta Description

Include:

- project name
- relevant deployment challenge
- HelloDeploy
- one important technical concept

Avoid generic descriptions.

## URL Pattern

Use:

```text
/case-studies/project-name
```

Examples:

```text
/case-studies/hellouniversity
/case-studies/hellorun
/case-studies/hellopera
```

## Page Metadata

Include:

- title
- description
- canonical URL
- Open Graph image
- author
- published date
- updated date

## Structured Data

Where appropriate, use Article or TechArticle schema.

Possible fields:

- headline
- description
- author
- datePublished
- dateModified
- image
- mainEntityOfPage

Do not add ratings or review scores.

## Breadcrumb

Example:

```text
Home > Case Studies > HelloUniversity
```

## Image SEO

Use:

- descriptive filenames
- descriptive alt text
- meaningful captions
- compressed images

Avoid generic names such as:

```text
image1.png
screenshot2.png
```
