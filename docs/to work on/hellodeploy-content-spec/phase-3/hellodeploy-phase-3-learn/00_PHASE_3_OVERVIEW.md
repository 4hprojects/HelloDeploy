# HelloDeploy Phase 3: Learn Content Overview

## Purpose

Phase 3 creates the educational content layer for HelloDeploy.

The goal is not to publish generic hosting articles.

The goal is to build useful, accurate, search-friendly technical content that helps readers understand deployment, hosting, DNS, servers, and security while naturally connecting those concepts to HelloDeploy.

## Phase 3 Strategy

Each article should:

- answer one real user question
- explain the concept clearly
- use practical examples
- include a HelloDeploy-specific angle where relevant
- link to documentation when the reader is ready to act
- avoid unsupported claims
- avoid filler
- avoid repeating the same explanation across multiple articles

## Article Creation Workflow

For each article:

1. Review the article brief.
2. Verify current technical details where needed.
3. Draft the article.
4. Add HelloDeploy examples only when verified.
5. Add original screenshots or diagrams where useful.
6. Add internal links.
7. Review against quality rules.
8. Publish only after factual and UX review.

## Important Rule

These files are editorial briefs, not final articles.

The content writer or agent should not invent HelloDeploy behavior. Product-specific claims must come from the actual platform and documentation.
