# Phase 3 QA Checklist

## Article Quality

For every article:

- [ ] Search intent is clear
- [ ] Title matches the actual topic
- [ ] Introduction answers the core question quickly
- [ ] Article contains meaningful examples
- [ ] No filler sections
- [ ] No fake statistics
- [ ] No unsupported HelloDeploy claims
- [ ] No duplicated content from another article
- [ ] Related internal links are included
- [ ] Relevant docs links are included
- [ ] Technical terminology is explained
- [ ] Examples are accurate
- [ ] Screenshots are sanitized
- [ ] Article is readable on mobile

## SEO

- [ ] Unique title
- [ ] Unique meta description
- [ ] One H1
- [ ] Logical headings
- [ ] Clean URL
- [ ] Canonical URL
- [ ] Open Graph metadata
- [ ] Article schema where appropriate
- [ ] Author
- [ ] Published date
- [ ] Updated date

## Originality

At least one of these should be present where relevant:

- [ ] HelloDeploy screenshot
- [ ] HelloDeploy example
- [ ] Real deployment lesson
- [ ] Original diagram
- [ ] Real troubleshooting example
- [ ] Original comparison or explanation

## Product Accuracy

Before publishing HelloDeploy-specific claims:

- [ ] Runtime support verified
- [ ] UI labels verified
- [ ] Documentation links exist
- [ ] Platform behavior verified
- [ ] No planned feature presented as currently available

## Phase Completion Target

Phase 3 first release is complete when:

- [ ] 15 or more substantial articles are published
- [ ] all major content clusters have internal links
- [ ] articles connect naturally to documentation
- [ ] no thin content exists
- [ ] at least several articles contain original HelloDeploy examples
