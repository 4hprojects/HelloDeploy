# Phase 2: Documentation

## Goal

Create documentation that explains how to use HelloDeploy.

Documentation is different from Learn content.

Documentation answers:

> How do I use HelloDeploy?

Learn content answers:

> How does this deployment concept work?

## Required Pages

- `/docs`
- `/docs/getting-started`
- `/docs/build-configuration`
- `/docs/start-command`
- `/docs/environment-variables`
- `/docs/domains`
- `/docs/deploy-hooks`
- `/docs/deployment-logs`
- `/docs/redeployment`
- `/docs/troubleshooting`

## Quality Rules

Every documentation page should include:

- purpose
- prerequisites
- steps
- expected result
- common mistakes
- related docs

Use screenshots where useful.

Never expose secrets, deploy hook URLs, private repository details, or credentials.
