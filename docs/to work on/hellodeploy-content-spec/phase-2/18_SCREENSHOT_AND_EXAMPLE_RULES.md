# Screenshot and Example Rules

## Use Screenshots When

A screenshot helps users locate a setting, button, field, status, log section, or domain configuration.

## Screenshot Safety

Remove or mask:

- passwords
- API keys
- tokens
- deploy hook URLs
- database connection strings
- personal email addresses when unnecessary
- private repository details
- sensitive internal identifiers

## Screenshot Freshness

Update screenshots when the UI changes significantly.

## Captions

Captions should explain what the user should notice.

## Code Examples

Use examples only when they are verified, relevant, minimal, and safe.

## Placeholder Values

Use obvious placeholders:

```text
example.com
your-project
YOUR_API_KEY
[HelloDeploy-provided value]
```

## Runtime Examples

Label runtime-specific examples. Do not imply one runtime's configuration applies to all runtimes.
